# 迁移指南：从手动加载到自动加载

## 概述

本指南展示如何从旧的手动路径配置方式迁移到新的自动加载方式。

## 迁移对比

### 旧方式（Cell 8 - 原版）

```python
# --- Load table descriptions and schema from local JSON and DB ---
from db_schema_loader import load_table_info

# Set your database and description file paths
db_path = "my_database_mimic.db"
descriptions_path = "sqlite_table_descriptions.json"

# Load table info and schema
table_names, table_names_and_infos, table_names_and_columns = load_table_info(db_path, descriptions_path)

# --- If you need DataFrames for each table, you can load them dynamically ---
import pandas as pd
from sqlalchemy import create_engine

engine = create_engine(f"sqlite:///{db_path}")
names_and_frames = {table_name: pd.read_sql_table(table_name, engine) for table_name in table_names}
```

**问题**：
- ❌ 需要手动指定数据库路径
- ❌ 需要手动指定描述文件路径
- ❌ 无法自动发现 tableinfos 目录
- ❌ 需要记住正确的文件名

### 新方式（Cell 8 - 改进版）✨

```python
# --- Auto-load table descriptions and schema from database ---
from db_schema_loader import auto_load_database
import pandas as pd
from sqlalchemy import create_engine

# Automatically discover and load:
# 1. Database file (my_database_mimic.db)
# 2. Table descriptions (sqlite_table_descriptions.json - generated by sqlite_table_description.py)
# 3. Table summaries (tableinfos/ directory)
# 4. Column names from database
table_names, table_names_and_infos, table_names_and_columns = auto_load_database(
    search_dir=".",  # Search in current directory
)

# Create database engine for querying
db_path = "my_database_mimic.db"
engine = create_engine(f"sqlite:///{db_path}")

# Optional: Load DataFrames for each table if needed
# names_and_frames = {table_name: pd.read_sql_table(table_name, engine) for table_name in table_names}
```

**优势**：
- ✅ 自动发现数据库文件
- ✅ 自动发现描述文件
- ✅ 自动发现 tableinfos 目录
- ✅ 智能合并多个描述来源
- ✅ 显示详细的加载信息
- ✅ 仍支持手动指定路径（向后兼容）

## 高级用法

### 指定不同的搜索目录

```python
table_names, table_infos, table_columns = auto_load_database(
    search_dir="/path/to/different/directory"
)
```

### 混合使用：部分自动，部分手动

```python
table_names, table_infos, table_columns = auto_load_database(
    db_path="custom_database.db",  # 手动指定数据库
    # descriptions_path 自动发现
    # tableinfos_dir 自动发现
)
```

### 完全手动（向后兼容）

```python
from db_schema_loader import load_table_info

table_infos, table_columns = load_table_info(
    db_path="my_database.db",
    descriptions_path="descriptions.json",
    tableinfos_dir="tableinfos"
)
table_names = list(table_columns.keys())
```

## 功能增强

### 1. 多源描述合并

新版本会自动合并多个描述来源：

**优先级**：
1. `sqlite_table_descriptions.json`（详细描述）
2. `tableinfos/*.json`（表摘要）
3. 空字符串（如果都没有）

**示例**：
```python
# 如果 sqlite_table_descriptions.json 中有详细描述
table_infos['PATIENTS']  # 返回详细描述

# 如果只有 tableinfos/0_PATIENTS.json
table_infos['PATIENTS']  # 返回简短摘要

# 如果都没有
table_infos['NEW_TABLE']  # 返回 ""
```

### 2. 自动发现数据库

优先选择包含特定关键词的数据库：
- `*mimic*.db`
- `*database*.db`
- 其他 `.db` 文件

### 3. 详细的加载反馈

新版本显示清晰的加载过程：
- ✓ 成功找到文件
- ⚠ 警告信息
- 表格列表和统计信息

## 故障排除

### 问题：函数未定义

**错误**：`NameError: name 'auto_load_database' is not defined`

**解决**：
```python
# 确保导入正确的函数
from db_schema_loader import auto_load_database
```

### 问题：找不到数据库

**错误**：`FileNotFoundError: No database file found`

**解决**：
1. 检查当前目录是否有 `.db` 文件
2. 或手动指定：`auto_load_database(db_path="/path/to/db.db")`

### 问题：没有描述

**现象**：所有表的描述都是空字符串

**解决**：
```bash
# 生成描述文件
python sqlite_table_description.py
```
